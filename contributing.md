## 🛠 Step-by-Step Manual Activation

### Step 1 — Open Command Prompt as Administrator
Press **Win + X** → **Windows Terminal (Admin)** or **Command Prompt (Admin)**.

### Step 2 — Navigate to Office Folder
Type the command that points to your Office installation directory (for example, `cd "C:\Program Files\Microsoft Office\Office16"`).

### Step 3 — Set the KMS Server
Run the command that points to a verified KMS server. The manual lists several backups in case one fails.

### Step 4 — Install the KMS Client Key
Enter the Office KMS client key that matches your edition (Pro Plus, Standard, Home, etc.). The manual provides the full key list.

### Step 5 — Trigger Activation
Run the activation command. Office will contact the KMS server and confirm the license.

### Step 6 — Verify in Office
Open any Office app → **File → Account**. You should see **"Product Activated"**.
